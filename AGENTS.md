- The whole site uses the Midnight Tech `--mn-*` tokens; shadcn semantic tokens in :root are mapped onto them. Why: one consistent dark identity, no legacy cream styles.
- Brand artwork is rendered through Logo.tsx: HeroBrandMark uses the original processed hero PNG, BrandMark retains the standalone SVG, and Logo uses the approved full-name PNG. Why: hero restoration must not alter other approved brand uses.
- Homepage is one scrolling page with anchors #home, #technology, #innovations, #perspective, #contact; only /privacy is a separate page. Why: continuous experience, no unnecessary pages.
- #home links (navbar logo, nav, mobile menu, footer Back to top) must scroll to the document top via `scrollToHome()` in `src/lib/scroll.ts`, never native anchor navigation. Why: #home sits inside the GSAP-pinned hero, so native anchors measure the fixed element and land at the end of the pin spacer (blank hero) or don't scroll at all.
- Scroll storytelling uses GSAP ScrollTrigger inside gsap.context + matchMedia (pin only for desktop hero; readable scrubbed editorial illumination in Perspective; none on reduced motion). Innovations uses native CSS sticky without overflow-constrained ancestors and animation-frame-throttled nearest-reading-line selection with resize cleanup. Why: reliable two-way product reading and native scroll without extra pin spacing.
- Hero quadrant imagery and Technology detail imagery are separate fields in the focus-area data. Why: each context needs distinct relevant visuals without changing focus copy.
- Hero quadrant links are inert until the animated panels are readable; mobile and reduced-motion visitors use static focus-area links to the same detail anchors. Why: hidden animated controls must not receive focus or intercept navigation.
- The contact form validates in `src/lib/enquiry.ts` and hands off to the visitor's email app (mailto); it never claims delivery. Why: no backend in V1, so no false success states.
- App images must be real files in src/assets imported via Vite, never `.asset.json` / `/__l5e/` pointers. Why: production is self-hosted on Cloudflare Pages, where Lovable asset routes do not exist.
